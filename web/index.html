Why EvalPro?

Everything You Need

A complete platform for academic project management and evaluation.

🔒

Secure Authentication

JWT-based authentication with bcrypt password hashing. Two-layer admin protection ensures only authorized supervisors access the dashboard.

📋

Project Submission

Students submit project proposals with documentation. Full submission review with feedback details and evaluation criteria selection.

📊

Evaluation Tracking

Track your project evaluation through all stages: Submitted → Under Review → Evaluated → Approved with real-time status updates.

🌟

Evaluation Rubrics

View grading criteria with live countdown timers. Supervisors can create and manage limited-time evaluation rubrics and criteria.

🔍

Smart Project Search

AI-powered search helps you navigate and discover projects by name, category, technology keywords, or student name instantly.

📱

Fully Responsive

Seamless experience on all devices — desktop, tablet, and mobile. Page loaders and smooth transitions on every page.
